# Written before this session painted anything

The question was set by the human before the run, in these words:

> If you want the Markus moment, the interesting question is whether that's the prior
> speaking or the painter, and the way to tell is to ask again. A second unprompted run
> from a fresh session, with the mug taken out of the guide first: if it's a sunset
> again, it's the prior; if it's something else, you've got something to compare.

Fixing what counts, now, so the reading cannot be chosen after seeing the picture.

## What is different about this run

Two variables were removed that REHEARSAL4's unprompted pair could not separate:

- **The guide no longer names either copy reference.** REHEARSAL4's session read a
  guide whose depth-order rule was written around the mug photograph. That is gone —
  `mug`, `cup`, `tea`, `spoon`, `handle`, `face`, `cheek`, `coat`, `sitter` are at zero
  across `PAINTER.md` and `CALIBRATION.md`, checked before launch.
- **There is no copy stage before it.** REHEARSAL4's unprompted paintings came after
  300 strokes on a mug. Nothing of the mug appeared in them, which is why the human
  concluded the subjects came from the painter rather than the copy — but this run
  removes the possibility entirely.

Everything else is REHEARSAL4's Stage 2, word for word.

## What the prior looks like, from the record

Every unprompted painting this engine has produced, by a session that had read the
guide:

| Run | Subject |
|---|---|
| REHEARSAL2 | A dawn estuary — layered sky, headland in fog, dark spit, posts, wet mud |
| REHEARSAL3 | An estuary at low tide — luminous sky, headland, three mooring posts, ribbons of wet sand |
| REHEARSAL4 | A sunset over water — bare tree, three birds, reeds, sun path |

Three for three: **a low sun over water, seen wide, built from horizontal bands.**
Separately, `rehearsal3/unprompted/` asked thirty-two fresh sessions to *name* a subject
without painting: 63% said a rain-wet street at dusk, and the ones given no guide
produced no estuaries at all — so the water-and-sky answer is something the guide
brings out, not the bare model's first instinct.

## The call, made now

**The prior repeating** = the first painting is a wide landscape organised around water
and sky: an estuary, shore, lake, sea, river, wet sand, marsh, or a low sun over any of
them. Any of those, whatever else is in it, is the same answer for the fourth time.

**Something to compare** = anything else. An interior, a figure, a still life, a close-up
of one thing, an object, a night scene without water, an abstraction, a built
environment. The subject does not have to be good to count as new information; it has to
be *not that*.

**The second painting is not being judged on subject at all.** It is defined against the
first by instruction, so it measures how this painter reasons about difference, not what
it would choose. `probe_structure.py`'s break criteria from `rehearsal4/PREREGISTERED.md`
still apply to it unchanged: at least 8 dB below the first on banding, and the edge split
reversed or levelled to within a factor of 1.5.

## What this run cannot settle

One painting. If it is a sunset again, that is a fourth data point for the prior and
worth acting on. If it is not, **one counter-example does not undo three** — it means the
subject is reachable, not that the prior is gone, and the honest next step would be
several cheap runs rather than one more conclusion. Said now, so it cannot be forgotten
if the picture is interesting.
